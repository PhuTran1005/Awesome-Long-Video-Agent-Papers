## Add a Method

Check both this list and the [taxonomy paper index](index.md) for duplicates, then submit a [paper suggestion](https://github.com/PhuTran1005/Awesome-Long-Video-Agent-Papers/issues/new?template=paper.yml) or a pull request.

Include the release date, method name, full paper title, and a short description of the contribution. Link to a primary publication page; include an official code repository or project page when available. Suggest one or more of the four taxonomy stages, or use **To be determined**.

Use red badges for arXiv links, blue badges for conference/journal papers, dark `Code` badges for GitHub repositories, and one color per stage for suggested categories (pink Acquisition, gold Memory, blue Control, green Verification). See the [badge examples](../CONTRIBUTING.md#badge-style) for reusable Markdown, including rounded venue/year badges and live GitHub star counts. Leave an undecided category as plain **To be determined**.

Provide the paper's BibTeX in the issue or pull request so maintainers can preserve its citation key when integrating it into the survey.

## From This List to the Taxonomy

1. Add the method here with its publication source and a provisional category.
2. Review its scope and mechanism against the survey's taxonomy.
3. Incorporate the paper into the manuscript taxonomy and bibliography, then update the generated catalog.
4. Remove its row from this list once it appears in the taxonomy index.

This page remains available for future additions as the survey and repository evolve.
